# 機構設計(Mechanical)

薄型化を重視するが、**通常高さのMX互換性と機械的強度を優先**する。

## 確定している機構要件

- 基本キーピッチ **19.05mm**、全キー1u、列スタッガー・回転なし
- 通常高さの**MX互換スイッチ**(3ピン/5ピン対応)+ Kailh MXホットスワップソケット
- **プレートなし構成にはしない**。**1.5mm厚のスイッチプレート**を用いた**薄型サンドイッチ構造**を基本案とする
  - Cherry公式データシート確認済み: **プレート開口14.0±0.05mm角(角R0.3max)、プレート厚1.5±0.1mm指定**([references.md](references.md))。1.5mm案は公式仕様どおり
  - 同データシートのPCB厚表記は約1.5mm(0.06±0.006in)→ **1.2mm板厚はCherryの想定外**であり、検証必須の追加根拠
- PCB厚は1.6mmを標準候補(1.2mmはソケット互換性・剛性確認後に判断)
- ホットスワップソケットと底板のクリアランスを最小化する
- キーLED等がないため、導光・透過に関する機構要件はない

## 基板・プレート外形の方針(確定)

- **PCB・プレート・ケースの外形は長方形にせず、キー領域に沿って切り欠く**([key-layout.md](key-layout.md) の外形方針に従う)。
- 具体的には、下段追加行(R4)は小指側3キー分のみ張り出し、その右側の下部領域(R4×C3–C6相当)は基板なし。親指側C6タブは1uキー+nice!view/nice!nano占有分のみ。
- ケース・プレートも同じ輪郭に追従させる(ケース余白・入隅Rは外形設計時に確定)。
- 注意点: 切り欠き形状のため、ねじ・スペーサー配置と剛性(特にC6タブと下段張り出しの根元)を外形設計時に確認する。

## 積層構造(基本案)

上から順に:

```
キーキャップ
MX互換スイッチ
スイッチプレート(約1.5mm)
(プレート〜PCB間の空間: MX規格による)
PCB(1.6mm標準候補)
ホットスワップソケット・ダイオード(PCB裏面)
(最小クリアランス)
底板
```

- **ホットスワップソケット(Kailh PG151101S11)のPCB裏面からの突出は1.85±0.1mm**(公式データシート確認済み)。PCB裏面〜底板の最小クリアランスはこの1.85mm+マージンが下限になる。
- Kailh公式の推奨レイアウトは**基板厚1.6mm前提**と明記されている。PCB1.2mm化はスイッチ保持力・ソケット嵌合の実物検証をしてから判断する(既存方針の根拠)。

- MXスイッチはプレート上面からPCB上面までの距離が規格で決まるため(データシートで確認)、薄型化の自由度は主に「PCB裏面〜底板」と「ケース縁の高さ」にある。
- スイッチのセンターポスト・固定ピンがPCBを貫通するため、底板との間に必要な逃げを確認する。

## nice!view / nice!nano の積層

- 追加1uキー(R3, C6)の真上の領域に **nice!view(公式確認済み: 14mm × 36mm、5ピン2.54mmピッチ)を縦向きに配置**し、その**下層にnice!nano(公式確認済み: 基板厚3.2mm、ミッドマウントUSB-C)を積層**する。
- 両方とも交換可能なソケット実装。ソケット+ピンヘッダの合計高さが確定するまで、この部分の最大高さは未確定。
- **nice!view装着中でも以下を操作可能にする**こと:
  - USB-C(ケース開口から抜き差し)
  - リセットボタン
  - 電源スライドスイッチ
- ソケットの具体部品(低背ソケット/コンスルー等)は未確定(ADR予定)。

## バッテリー配置

- 左右それぞれにLiPoを収納する。配置場所は未確定(候補: PCB下の空間のうちホットスワップソケット・アンテナ禁止領域と干渉しない領域)。
- **保護要件**:
  - ソケット・はんだ接合部の突起がバッテリーに接触しない構造にする
  - 底板との間で圧迫しない
  - **膨張余裕**(厚み方向のマージン)を確保する
- バッテリー寸法・容量は未確定。ケース内寸確定後に決める([product-requirements.md](product-requirements.md) 未確定事項)。

## ケース開口・操作部

| 操作部 | 要件 |
| --- | --- |
| USB-C | ケース装着後も抜き差し可能な開口 |
| リセットボタン | ケース外から操作可能(開口またはピンホール) |
| 電源スライドスイッチ | ノブをケース**側面**から操作可能。ON/OFF位置を目視・触覚で判別可能。ケースまたはPCBにON/OFF表示。ノブの突出量を抑えて誤操作を防ぐ。**配置方針(2026-09-08、暫定): C6タブの外周側面、nice!view下部〜親指キー横**(アンテナkeep-outから離れ、nice!view/nano・JSTと近く配線が短い)。右半分はミラー |

## アンテナ周辺

- nice!nanoのアンテナ端周辺は**非金属化**する: 金属プレート・ねじ・バッテリー・金具を配置しない。
- プレートを金属にする場合でも、アンテナ上方は切り欠くか非金属材にする(材質未確定のため後続フェーズで具体化)。

## ケース製作方針(2026-09-08確定、ADR-0008)

- **フル樹脂の削り出しを基本方針**とする(POM/PC候補、具体材質未定)。フルアルミはアンテナ遮蔽のため不採用。
- 進め方: PCBレイアウト確定 → **3Dプリント試作**(干渉・開口・BLE実測検証)→ 樹脂削り出し発注。
- CADはCadQuery等でのスクリプト生成を基本とし、PCB外形に追従させる。発注データは `production/<revision>/` に凍結。
