# 製造方針(Manufacturing)

**現在はまだ発注可能な状態ではない。** 回路図・PCBが存在せず、製造前検証も未実施。

## Rev.Aの方針

- **Rev.AはPCBのみを発注し、手実装する。**
  - ケース・プレートの発注はRev.A評価後(または並行検討だが、初回発注には含めない)。
  - 部品(ダイオード、ソケット、JST、スライドスイッチ等)は別途調達し手はんだ。
- Rev.Aの評価結果を [revisions/rev-a.md](revisions/rev-a.md) に記録し、必要ならRev.Bで修正する。
- 左右別PCBかリバーシブルPCBかは未確定(ADRで比較・提案予定)。発注枚数・費用に影響する。

## 製造データの配置場所

| データ | 場所 |
| --- | --- |
| KiCadソース(編集可能) | `hardware/kicad/` |
| Gerber・ドリル | `production/rev-a/gerbers/` |
| BOM | `production/rev-a/bom/` |
| 座標データ(CPL) | `production/rev-a/placement/` |

- **製造データは `production/<revision>/` へ凍結保存する。** 発注に使った実データのスナップショットであり、発注後は編集しない。修正は次リビジョン(`production/rev-b/` 等)として作成する。
- 生成物を `hardware/` 配下に置かない(ソースと生成物の分離。AGENTS.md参照)。

## 発注前に必要な検証

[verification-checklist.md](verification-checklist.md) の「製造前チェックリスト」がすべて完了していること。特に:

1. ERC / DRC がエラーなしで通ること
2. 全フットプリントが実部品データシートと照合済みであること(未検証フットプリントの使用禁止)
3. JST極性・ダイオード方向・左右反転・アンテナ禁止領域の確認
4. 製造業者のデザインルール(最小パターン幅・ドリル径等)との整合確認
5. 発注仕様(板厚・層数・表面処理等)の明文化

## 未確定の製造条件

- PCB厚(1.6mm標準候補 / 1.2mmは検証後判断)
- 層数(2層を第一候補とするが、配線検討後に確定)
- 表面処理・レジスト色・シルク内容
- 発注先の製造業者
- 発注枚数(左右別PCBかリバーシブルかに依存)

## 表現に関するルール

製造前チェックリストが完了するまで、このリポジトリ内で「製造可能」「production-ready」「検証済み」と表記しない(AGENTS.md参照)。
