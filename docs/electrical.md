# 電気設計(Electrical)

現時点で確定している電気要件と、未確定事項の候補・検証方法を記録する。
**マトリクス構成(5行×7列)とGPIO割り当ては確定済み**([decisions/0002](decisions/0002-matrix-and-gpio.md)、2026-09-08承認)。PCB配線の都合によるRow/Col個別ピンの入れ替えのみあり得る(その場合は回路図・本GPIO表・ZMK設定を同時更新)。

## 確定している電気要件

- マイコン: nice!nano v2(または互換のPro Micro形状nRF52840)、低背ソケット実装
- 全28キー(片側)にマトリクス用ダイオードを1個ずつ設ける
- スイッチはKailh MXホットスワップソケット経由で接続
- nice!viewを5ピン(MOSI / SCK / VCC / GND / CS、2.54mmピッチ)で接続、ソケット実装
- 左右それぞれに: 3.7V LiPo + 2ピンJSTコネクタ、2ポジション式電源スライドスイッチ、リセットボタン
- 充電はnice!nanoのUSB-C経由(内蔵充電回路: 標準約100mA、BOOSTジャンパで約500mA ※500mAh超バッテリー限定)
- バッテリー残量測定はnice!nano v2のVDDH測定(`zmk,battery-nrf-vddh`)→ **ADC用GPIO不要**
- キーLED・RGB・アンダーグローの回路は設けない
- Bluetoothアンテナ禁止領域を基板上に確保する(銅箔・ベタGND含め非配置)

## マトリクス方式(確定: 5行×7列)

| 候補 | 構成 | 必要GPIO | 評価 |
| --- | --- | --- | --- |
| **A. 物理一致 5行×7列**(採用) | 35座標中28使用 | 12 | 配線が物理配置と一致し最も素直。デバッグ容易。GPIOは18ピン中15ピン(nice!view除く)で収まり、予備3ピン残る |
| B. 詰め替え 4行×7列 | 28座標ぴったり | 11 | GPIO1本節約できるが、R4の3キーとR3C6を電気的に別の行へ折り込むため配線が交差し、手実装・デバッグ時の混乱リスクが増える |

- **決定: 候補A(5行×7列)**(ADR-0002)。diode directionはcol2rowを第一候補とする。GPIOに余裕があり節約の必要がないため、追跡しやすさを優先。
- ZMKのkscanは `col2row`(COLから出力、ROWで読む方向はZMK設定に従う)を第一候補とし、ダイオードはスイッチ→ROW方向(カソード=ROW側)で統一する。最終的な向きはkscan設定確定時に回路図と同時にレビューする。
- 右半分も同一のマトリクス構成(左右対称)。ZMKのmatrix transformで56キーへ合成する。

## nice!view配線(確定: ZMK標準)

ZMK公式 `nice_view_adapter` の標準割り当てに合わせる(独自ピンにするとshield定義の流用性が下がるため):

| nice!view側ピン | 接続先 | 備考 |
| --- | --- | --- |
| MOSI | D2 = P0.17 | SPIM_MOSI |
| SCK | D3 = P0.20 | SPIM_SCK |
| VCC | nice!nano VCC(3.3V) | P0.13のMOSFETで遮断可能な系統。スリープ時に表示電源を切れる |
| GND | GND | |
| CS | D1 = P0.06 | **active-high**(ZMK定義) |

- MISOは不要(Sharpメモリ液晶は書き込み専用)。SPIMのMISO割り当てはヘッダー外のP0.25ダミーでよい(ZMK標準と同じ)。
- nice!view(14×36mm)はR3C6キーの真上に縦向き配置([key-layout.md](key-layout.md))。基板上は5ピンソケットを配置する。

## 電源スイッチ配線(候補)

- 候補A(第一候補): **BATTERY+ ラインにスライドスイッチを直列挿入**(JST+ → スイッチ → nice!nano BATTERY+)。OFFで完全遮断。
- 検証事項: OFF状態でUSB-Cを挿した場合の挙動(充電回路はBATTERY+側にあるため、**OFF中は充電されない**はず。仕様として許容するか確認)、スイッチの定格電流(充電時最大500mA以上を推奨)。
- 公式の推奨接続位置は文書で確認できていないため、回路図作成時にnice!nano回路図(Charging and Power Pathブロック)と突き合わせる。

## リセット回路

- RESETピンをGNDへ落とすタクトスイッチ(ダブルタップでUF2ブートローダ)。型番・ケース開口方法は未確定。

## テストパッド(候補)

- VBAT(スイッチ後)、VCC(3.3V)、GND、RST、予備GPIO(D0 / D20 / D21)、必要に応じて各Row/Col。基板設計時に確定。

## アンテナ禁止領域

- **公式のkeep-out推奨寸法は確認できていない**(公式docsに記載なし)。
- 方針: nice!nanoのアンテナ端(USB-Cと反対側)の下および周辺に全層銅箔禁止・部品/ねじ/バッテリー禁止の領域を設ける。具体寸法は参考設計とnRF52840モジュール一般則を調査してADRで確定する。
