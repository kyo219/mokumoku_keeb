# ADR-0008: ケースはフル樹脂削り出し方針(POM/PC候補)

## Status

**Accepted**(2026-09-08 ユーザー承認。「いったん」の方針決定であり、Rev.B以降での再検討余地を明記)

## Context

ケースを削り出しで製作したい意向がある一方、本機は完全無線(BLE)であり、
アンテナ周辺の金属はADR-0007のkeep-out方針および要件(アンテナ周辺の非金属化)と衝突する。

検討した構成:

1. アルミ筐体+アンテナ部のみ樹脂窓 — 質感・剛性は最良だが加工が複雑、RF検証前に金属範囲を確定するリスク
2. アルミ+樹脂のハイブリッド(例: アルミボトム+樹脂トップ) — 妥協点だが接合設計が増える
3. **フル樹脂削り出し(POM / ポリカーボネート等)** — RF問題が原理的に発生しない、加工も単純

## Decision

**ケースはフル樹脂の削り出しを基本方針とする。** 材質はPOM / PCを第一候補群とし、具体材質・色は未確定。

進め方: PCBレイアウト確定 → **3Dプリントで試作ケース**(干渉・開口・BLE実測の検証)→ 問題なければ樹脂削り出しを発注。

## Alternatives

| 案 | 不採用理由 |
| --- | --- |
| フルアルミ | アンテナを金属で囲いBLE性能を大きく損なう(要件違反) |
| アルミ+樹脂窓 | Rev.Aでのアンテナ実測前に金属範囲を決めるのはリスクが大きい。**Rev.B以降、実測結果を踏まえて再検討可**(その場合は本ADRをSupersede) |

## Consequences

- ケース起因のRF制約が消えるため、ケース設計の自由度が上がる(アンテナ直上の開口・薄肉化が不要)。
- プレート材質(未確定)は引き続きアンテナ上方の非金属化ルールに従う(金属プレート採用時はアンテナ部切り欠き)。
- CADはCadQuery等のスクリプト生成を基本とし、PCB外形データに追従させる([../mechanical.md](../mechanical.md))。
- 発注データ(STEP・図面・材質仕様)は `production/<revision>/` に凍結する。

## Verification

- 3Dプリント試作で: 部品干渉、USB-C/スライドSW/リセット開口、打鍵時の剛性、バッテリー収納・膨張余裕を確認。
- bring-up手順10-11のBLE実測(ケース装着状態でも確認)。
- 削り出し発注前に、工具径由来の内隅R・最小肉厚・公差をベンダーのDFMガイドと照合。
