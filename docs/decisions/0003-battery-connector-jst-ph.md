# ADR-0003: バッテリーコネクタはJST PH(2.0mm)、S2B-PH-SM4-TB(LF)(SN)

## Status

**Accepted**(2026-09-08 ユーザー承認。**極性は実バッテリー確認まで未確定**)

## Context

左右各1個の2ピンバッテリーコネクタが必要([../product-requirements.md](../product-requirements.md))。薄型構成のため低背であること、手実装可能であること、脱着で消耗しにくいことが求められる。

確認済み情報([../references.md](../references.md)):

- JST PHシリーズ: 2.0mmピッチ、定格2A/100V。公式資料は [ePH.pdf](https://www.jst-mfg.com/product/pdf/eng/ePH.pdf)
- S2B-PH-SM4-TB(LF)(SN): 2ピン・**表面実装・横型(サイドエントリー)**。自作キーボードで最も一般的なバッテリーコネクタ

## Decision

**JST PH 2.0mm、基板側は S2B-PH-SM4-TB(LF)(SN)(SMD横型2ピン)を採用する。**

ただし**ピン極性(+/−の割り当て)は未確定のまま**とし、購入するバッテリー実物のリード極性を確認してから回路図で確定する(市販LiPoのPHコネクタ極性は統一されていないため)。

## Alternatives

| 案 | 概要 | 不採用理由 |
| --- | --- | --- |
| B2B-PH-K-S(スルーホール縦型) | 同PHシリーズの縦型 | 縦型は挿抜方向が上向きになり薄型ケースと相性が悪い。スルーホールは裏面に足が突出し、バッテリー保護要件と干渉しやすい |
| Molex PicoBlade等 1.25mmピッチ | より小型 | 定格・機械強度が小さく、手実装や挿抜に不利。市販LiPoのPH品揃えが最多 |
| 直はんだ(コネクタなし) | 部品削減 | 交換性・組立性が悪く、要件(コネクタ搭載)に反する |

## Consequences

- バッテリーはJST PHコネクタ付きの3.7V LiPoから選定することになる(ADR未定の容量・寸法選定の前提条件)。
- 横型のため、基板端付近に挿抜方向の空間を確保するレイアウト制約が生じる。
- SMDだが端子が大きく手はんだ可能。

## Verification

- 発注前チェックリスト: 基板側フットプリント・シルクの極性表示と、購入バッテリーの実物極性をテスターで照合(bring-up手順3にも組込み済み)。
- フットプリントはJST公式図面(ePH.pdf)と照合してから使用する。
