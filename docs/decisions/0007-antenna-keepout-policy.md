# ADR-0007: アンテナ禁止領域の設計方針

## Status

**Accepted**(2026-09-08 ユーザー承認。寸法は暫定値であり、Rev.A実測で検証する)

## Context

nice!nanoのnRF52840はオンボードアンテナ(USB-Cと反対側の基板端)でBLE通信する。要件としてアンテナ禁止領域の確保が必要だが、**nice!nano公式ドキュメントにはkeep-out推奨寸法の記載がない**([../references.md](../references.md))。

一般的な2.4GHz PCBアンテナの設計指針(非公式の一般則):

- アンテナ直下は全層で銅箔(ベタGND・配線・ビア)を除去する
- アンテナ同一層で15mm程度、他層で6mm以上のクリアランスが目安とされる
- 金属部品・バッテリー・ねじ等の金属をアンテナ近傍に置かない

## Decision

以下を設計ルールとする(暫定値):

1. **nice!nanoはアンテナ端をキーボード外周側(基板端)へ向けて配置**する。可能ならアンテナ部を基板端ぎりぎりに寄せ、母板がアンテナの先に延びない配置を優先する。
2. 母板上の**アンテナ投影領域+周囲5mm以上**を全層keep-out(銅箔・配線・ビア・部品・ねじ穴禁止)とする。アンテナ先方向は基板端まで開放する。
3. **バッテリー・金属プレート・ねじ・スペーサーはkeep-out領域とその上下空間に配置しない**([../mechanical.md](../mechanical.md) の非金属化要件と連動)。
4. アンテナ投影領域の正確な位置・幅は、nice!nano公式ピン配置図・実測から起こした検証済みフットプリントで定義する。

## Alternatives

| 案 | 概要 | 不採用理由 |
| --- | --- | --- |
| アンテナ部を母板から完全にオーバーハングさせる | 電気的に最良 | 外形・ケース設計の制約が増える。基板端配置+keep-outで十分と判断(Rev.Aで実測検証) |
| keep-outなし(ベタGNDをアンテナ下まで) | 配線が楽 | 2.4GHzアンテナの一般則に明確に反し、BLE性能劣化のリスク大 |
| 15mm以上の大型keep-out | より保守的 | C6タブ周辺の面積制約と衝突。5mm+基板端開放を暫定とし、実測で不足なら拡大 |

## Consequences

- nice!nano配置は「アンテナ=外周向き」が確定し、PCBレイアウトの初期条件になる。USB-C(反対側)はキー領域側を向くため、**USB-Cケーブルの取り回しとケース開口方向は機構設計で要検討**。
- keep-out領域はKiCadのrule area(全層)として定義し、DRCで機械的に検証できるようにする。

## Verification

- 設計チェックリスト: keep-out領域に銅箔・部品・ねじ穴がないこと(既存項目)。
- bring-up手順10-11: 左右間・ホスト間BLEの接続距離を実測し、実用性能(同室内で安定接続)を確認。不足ならRev.Bでkeep-out拡大またはオーバーハング化。
- 参考にした一般則は非公式のため、より信頼できる参考設計(FelixKeeb等の実績あるnice!nanoボード)のkeep-out実例を確認したら本ADRに追記する。
