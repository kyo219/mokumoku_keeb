# ADR-0006: nice!nanoはコンスルー実装(第一候補)、nice!viewは2.54mm低背ソケット

## Status

**Accepted**(2026-09-08 ユーザー承認。**具体型番と高さは図面確認後に本ADRを更新**)

## Context

nice!nanoとnice!viewの両方を交換可能なソケット実装にする要件([../product-requirements.md](../product-requirements.md))。積層(nice!viewがnice!nanoの上)のため、各層の高さが機構設計に直結する。

前提(確認済み):

- nice!nanoはPro Micro形状、片側12ピン×2列(2.54mmピッチ)、ミッドマウントUSB-Cで基板厚3.2mm
- nice!viewは5ピン(2.54mmピッチ)

## Decision

1. **nice!nano: コンスルー(Mac8系スプリングピンヘッダ、12ピン×2)を第一候補**とする。
   - nice!nano側へのはんだ付けが不要で、完全に無加工のまま交換できる(交換性が最も高い)
   - 国内(遊舎工房等)で入手性が高く、Helix/Corne系キットでの実績が多い
   - 高さ候補: 2.5mm / 3.5mm(**型番と正確な高さ・対応基板厚は公式図面で確認してから確定**)
2. **nice!view: 2.54mmピッチ5ピンの低背ピンソケット(メスヘッダ)+ nice!view側ピンヘッダ**とする。
   - 高さは、下層のnice!nano上面(コンスルー高+3.2mm)+クリアランスから逆算して選定する(未確定)

## Alternatives

| 案 | 概要 | 不採用理由 |
| --- | --- | --- |
| Mill-Max 315系低背ソケット + マシンピン | 最薄クラスの実績ある方式 | nice!nano側にピンのはんだ付けが必要で交換性が一段落ちる。コンスルー入手難・高さ不適合の場合の**代替候補として保持**(315-43-112-41-003000等) |
| 通常のピンヘッダ+ソケット直付け | 安価 | 背が高く薄型化に反する |
| 直はんだ | 最薄 | 交換可能要件に反する |

## Consequences

- PCBのnice!nano用スルーホールはコンスルー対応(めっきスルーホール、推奨穴径は公式図面確認後に確定)とする。Mill-Max代替でも同じ2.54mmピッチ穴を共用できる見込み(穴径互換は要確認)。
- nice!view装着高はnice!nanoスタックより上になるため、ケース最厚部はこの積層で決まる([../mechanical.md](../mechanical.md))。
- コンスルーの向き・挿抜方法をビルドガイドに記載する必要がある(将来)。

## Verification

- コンスルーの型番・高さ・対応基板厚・推奨穴径をメーカー公式図面(Mac8)で確認し、本ADRを更新してから回路図・フットプリントに反映する。
- 積層高さの計算表を [../mechanical.md](../mechanical.md) に追加し、USB-C開口・ケース高と整合することを確認する。
- Rev.A実機で挿抜・接触安定性を確認(bring-up手順5・9)。
