# ADR-0004: 電源スライドスイッチはAlps Alpine SSSS811101

## Status

**Accepted**(2026-09-08 ユーザー承認。BOOST不使用・バッテリー500mAh以下方針を含む)

## Context

左右各1個、明確なON/OFF位置を持つ2ポジション式スライドスイッチが必要。ケース側面から操作、突出量を抑える、薄型構成([../product-requirements.md](../product-requirements.md))。

確認済み情報(公式製品ページ、[../references.md](../references.md)):

- **Alps Alpine SSSS811101**: 単極・2ポジション、表面実装、本体6.7×2.6×1.4mm(高さ1.4mm)、アクチュエータ高1.1mm、トラベル1.5mm、動作温度-40〜+85℃
- **定格: 0.3A 5V DC(max)/ 50μA 3V DC(min)**
- ZMK系無線キーボード(Corne等)で広く採用実績がある

## Decision

**Alps Alpine SSSS811101 を採用する。**

付随する重要な制約: 定格0.3Aのため、**nice!nanoのチャージブースト(約500mA充電)は使用しない**。充電は標準の約100mAのみとする。これはバッテリー容量選定(未定ADR)の前提になる(大容量にしても充電が遅いだけでなく、公式もブーストは500mAh超専用としているため、**500mAh以下のバッテリーを選ぶ方針と整合**する)。

## Alternatives

| 案 | 概要 | 不採用理由 |
| --- | --- | --- |
| 汎用SS-12D00系(スルーホール縦型) | 定格に余裕、安価 | 背が高く薄型化に不利。SMD低背で実績のあるSSSS811101を優先 |
| Copal(Nidec)CUS-12TB等 | 同クラスのSMD小型 | 同等候補だが、キーボード用途での採用実績と入手性でSSSS811101を優先。入手難の場合の代替候補として保持 |
| 電源スイッチなし(ソフトOFFのみ) | 部品削減 | 要件(物理2ポジションスイッチ)に反する |

## Consequences

- 挿入位置はBATTERY+ライン直列([../electrical.md](../electrical.md) 候補A)。充電電流(約100mA)+動作電流はスイッチ経由となり、定格0.3A内に収まる。
- **BOOSTジャンパは基板上で使用禁止**(シルクまたはドキュメントで明示)。
- 低背1.4mm+アクチュエータ1.1mmのため、ケース側面開口はノブ位置を精密に合わせる必要がある(機構設計への申し送り)。
- ON/OFF表示はシルクで基板に印字する(要件)。

## Verification

- フットプリントと寸法をAlps公式図面と照合してから使用する(公式ページの寸法表記と流通データの差異があるため、**公式PDF図面の取得・照合を必須**とする)。
- bring-up手順12でON/OFFの確実な断続を実測確認。
- 充電中(USB接続時)のスイッチOFF挙動を実機確認(OFF中は充電されない想定の検証)。
