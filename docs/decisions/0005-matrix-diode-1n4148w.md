# ADR-0005: マトリクスダイオードは1N4148W(SOD-123)

## Status

**Accepted**(2026-09-08 ユーザー承認)

## Context

全56キー(片側28)に逆流防止ダイオードが必要。手実装のため、はんだしやすいパッケージが望ましい。

確認済み情報(複数メーカーのデータシート、[../references.md](../references.md)):

- **1N4148W**: 小信号高速スイッチングダイオード、**SOD-123**パッケージ、VR 75V / VRRM 100V、IF 150mA、trr約4ns。複数メーカー(Vishay、Diodes Inc.、MCC等)が製造する定番セカンドソース品

## Decision

**1N4148W(SOD-123)を採用する。** メーカーは入手性で選んでよい(セカンドソース互換)。

## Alternatives

| 案 | 概要 | 不採用理由 |
| --- | --- | --- |
| 1N4148(スルーホール) | 更に手はんだしやすい | 両面に足が出て薄型化・バッテリー保護と干渉。SOD-123は十分手はんだ可能 |
| 1N4148WS / 1N4148WT(SOD-323/523) | より小型 | 手実装の難度が上がる。小型化の必要がない |
| ショットキー(BAT54等) | VF低 | マトリクス用途に利点がなく、リーク電流が大きい |

## Consequences

- キーマトリクス(5V未満・数mA)に対し定格は十分。
- SOD-123はPCB裏面(ソケット面)実装を想定。高さはKailhソケット(1.85mm)より低く、底板クリアランスの支配要因にならない。
- 回路図では全ダイオードの向きをcol2row方針([0002](0002-matrix-and-gpio.md))と一致させる。

## Verification

- フットプリントを採用メーカーのデータシート推奨パッドと照合。
- 発注前チェックリスト: ダイオード方向の全数確認(既存項目)。
