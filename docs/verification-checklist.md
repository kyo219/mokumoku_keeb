# 検証チェックリスト(Verification Checklist)

設計 / 製造前 / 組立後 の3段階。**すべての製造前チェックが完了するまで「production-ready」と表記しない。**

## 1. 設計チェックリスト(回路図・PCB作成中〜完了時)

- [ ] キー配列が [key-layout.md](key-layout.md) と一致している(片側28キー、R0–R3×C0–C5 + R4×C0–C2 + R3×C6)
- [ ] 右半分が左半分の完全な左右反転になっている
- [ ] 全キーにダイオードがあり、方向がマトリクス全体で一貫している
- [ ] GPIO表・回路図・ZMK設定のピン割り当てが一致している
- [ ] nice!view(5ピンSPI)の配線が公式ピン配置と一致している
- [ ] nice!nano・nice!viewがソケット実装になっている
- [ ] 電源スライドスイッチ・リセットボタン・JSTコネクタが左右両方にある
- [ ] JST極性が使用予定バッテリーの公式資料と一致している
- [ ] アンテナ禁止領域に銅箔(全層)・部品・ねじ穴がない
- [ ] nice!view装着状態でUSB-C・リセット・スライドスイッチが操作可能な配置である
- [ ] 使用した全フットプリントが実部品データシートと照合済み(照合記録あり)
- [ ] 外部設計を参考にした箇所の出典・ライセンスが [references.md](references.md) に記録されている
- [ ] ERCがエラーなしで通る
- [ ] DRCがエラーなしで通る

## 2. 製造前チェックリスト(発注直前)

- [ ] 設計チェックリストがすべて完了している
- [ ] 未確定事項([product-requirements.md](product-requirements.md))のうち、発注に影響する項目がすべて確定・ADR記録済み
- [ ] PCB厚・層数・表面処理などの発注仕様が明文化されている
- [ ] 製造業者のデザインルールでDRCを再実行しエラーなし
- [ ] Gerber・ドリルデータをビューアで目視確認した(層ずれ・欠落・鏡像違いがない)
- [ ] 左右別PCBの場合: 両方のGerberが揃っている / リバーシブルの場合: 両面使用の整合を確認した
- [ ] BOM・座標データ(必要な場合)が実部品型番と一致している
- [ ] 製造データ一式を `production/rev-a/` に凍結した
- [ ] 発注内容(枚数・仕様・費用)をユーザーが承認した

## 3. 組立後チェックリスト(手実装後)

- [ ] [bring-up.md](bring-up.md) の手順1〜15を順番に実施し、結果を記録した
- [ ] 左右両方で実施した
- [ ] 全56キーの入力を確認した
- [ ] バッテリー駆動・充電・スライドスイッチ断を確認した
- [ ] BLE接続性(左右間・ホスト間)を実使用距離で確認した
- [ ] スリープ時消費電流を実測・記録した
- [ ] NG項目・改善点を [revisions/rev-a.md](revisions/rev-a.md) に記録した
- [ ] Rev.Bが必要か判断し、必要ならADRを起票した
