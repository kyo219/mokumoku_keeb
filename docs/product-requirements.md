# 製品要件定義(Product Requirements)

**このドキュメントが仕様の一次情報です。** 他のドキュメントと矛盾した場合はこちらが正です。

- プロジェクト名: **mokumoku-keeb(仮称)** — リポジトリ名由来の仮slug。正式名は未定。
- ステータス: 初期整備フェーズ(設計段階、製造検証前)

## 1. 確定要件

### 製品コンセプト

- 左右分割型・Bluetooth対応・バッテリー駆動のオーソリニアキーボード
- 通常高さのMX互換スイッチを使用しつつ、LEDを省略し、省電力かつ可能な限り薄い構造を目指す
- 薄型化より、MX互換性と機械的強度を優先する

### キー配列(詳細は [key-layout.md](key-layout.md))

- 左半分を基準に設計し、右半分は完全な左右反転形状
- 基本4行×6列のオーソリニア24キー + 小指側3列の第5行3キー + 親指側1uキー1個 = **片側28キー、左右合計56キー**
- 全キー1u、基本キーピッチ19.05mm
- 列スタッガー・キー回転は使用しない
- 追加の1uキーはSpace専用ではなく汎用キーとして扱う

### スイッチ

- 通常高さのCherry MX互換スイッチ(3ピンおよび5ピン対応)
- Kailh MXホットスワップソケット
- Kailh Choc等のロープロファイル規格には**対応しない**
- 全キーにマトリクス用ダイオードを設ける
- キーLED・RGB LED・アンダーグローは**搭載しない**

### マイコン・無線

- 左右それぞれに独立したnRF52840マイコン
- nice!nano v2、または互換性が明確なPro Micro形状のnRF52840マイコン
- Raspberry Pi Pico / RP2040 は**使用しない**
- マイコンは交換可能な低背ソケット実装
- ファームウェアはZMK
- ホスト接続・左右間接続ともにBluetooth LE(TRRS等の有線接続は使用しない)
- ケース装着後もUSB-Cを利用可能にする
- Bluetoothアンテナの禁止領域(keep-out)を確保する

### nice!view

- ディスプレイはnice!view専用(OLED互換性は不要)
- 標準的な5ピン接続とSPI配線に対応
- 左半分では親指側追加1uキー(R3, C6)の真上へ縦向きに配置、右半分は左右反転
- nice!viewの下に重なるようにnice!nanoを配置
- nice!view・nice!nanoともに交換可能なソケット実装
- 電源スイッチ・リセット・USB-Cはnice!view装着中も操作可能にする
- nice!viewはキー数に含めない

### バッテリー・電源

- 左右それぞれ独立した3.7V LiPoバッテリーで駆動
- 左右それぞれに2ピンJSTバッテリーコネクタを搭載
- nice!nanoのUSB-C経由で充電
- 左右それぞれにリセットボタンを設置
- 電源はON/OFF位置が明確な2ポジション式スライドスイッチ
  - スライドノブはケース側面から操作可能
  - ON/OFF状態を目視および触覚で判別可能にする
  - PCBまたはケースにON/OFF表示を設ける
  - 持ち運び中の誤操作を防ぐため、ノブの突出量を抑える
- LiPoをソケット・はんだ接合部・底板から保護し、膨張余裕を確保する

### 開発プロセス

- 初号機(Rev.A)はPCBのみを発注し、手実装する
- Rev.Aを評価し、必要に応じてRev.Bで修正する
- 未確認の寸法・ピン配置・極性・フットプリントを推測で確定しない
- 「製造可能」「検証済み」「production-ready」等の表現は条件を満たすまで使用しない

## 2. 推奨要件(基本案。検証結果により変更可)

- プレートなし構成にはせず、**薄型サンドイッチ構造**を基本案とする
- スイッチプレートは約**1.5mm厚**を検討する
- PCB厚は**1.6mmを標準候補**とし、1.2mmは互換性(ホットスワップソケット・スイッチ保持力)と剛性を確認してから判断する
- ホットスワップソケットと底板のクリアランスを最小化する
- アンテナ周辺へ銅箔・金属プレート・バッテリー・ねじを配置しない

## 4. 対象外(スコープ外)

- キーLED・RGB LED・アンダーグロー
- Kailh Choc等のロープロファイルスイッチ対応
- OLEDディスプレイ互換
- TRRS等の有線での左右接続
- Raspberry Pi Pico / RP2040系マイコン
- 列スタッガー・キー回転を伴う配列
- (初期フェーズでは)KiCad回路図・PCB・Gerber・製造データ・ケースCADの完成、製造発注、外部サービスへのアップロード

## 5. 初号機(Rev.A)の成功条件

Rev.A(PCBのみ発注・手実装)が以下をすべて満たすこと:

1. 短絡・逆極性なくUSB-Cから給電・充電できる
2. nice!nanoがソケット実装で認識され、ZMKを書き込める
3. 全56キーがマトリクスとして正しく入力される(ゴースト・チャタリングの構造的問題がない)
4. nice!viewがソケット実装で表示動作する
5. 左右間がBLEで接続され、ホストともBLE接続できる
6. 左右それぞれがバッテリー単独で駆動する
7. アンテナ禁止領域が確保され、実用的なBLE接続性が得られる
8. ケース装着を想定した部品高さ・開口位置に致命的な干渉がない(ケース自体はRev.A時点で完成していなくてよい)

満たせなかった項目はRev.Bの修正対象として [revisions/rev-a.md](revisions/rev-a.md) に記録する。
