# 初号機(Rev.A)Bring-up手順

Rev.A(PCBのみ発注・手実装)の動作確認手順。**必ずこの順序で実施**し、結果を [revisions/rev-a.md](revisions/rev-a.md) に記録する。

前提: 手実装が完了していること。ただし**バッテリーとnice!nanoは接続しない状態から開始**する。

## 手順

1. **目視検査**
   - はんだブリッジ、未はんだ、部品の向き(ダイオード極性、JST極性、ソケット方向)を全数確認
2. **電源短絡確認**(無通電)
   - テスターでVCC–GND間、VBAT–GND間の短絡がないことを確認
3. **JST極性確認**
   - 使用するバッテリー実物の極性と基板側シルク・配線が一致することをテスターで確認(**接続前に必ず**)
4. **USB給電**
   - バッテリー未接続のままnice!nanoをソケットに装着し、USB-Cから給電。発熱・異臭がないこと
5. **マイコン認識**
   - ホストPCがnice!nano(ブートローダ)を認識すること
6. **ZMK書き込み**
   - ビルド済みZMKファームウェアを書き込み、起動すること
7. **単キー入力確認**
   - 任意の1キーにスイッチを挿し、USB接続で入力されること(ホットスワップソケットの導通確認を兼ねる)
8. **全キーマトリクス確認**
   - 全28キー(片側ずつ)が正しいキーコードで入力されること。同時押しでゴーストがないこと
9. **nice!view確認**
   - nice!viewをソケットに装着し、表示されること
10. **左右無線接続**
    - 左右をペアリングし、peripheral側の入力がcentral経由でホストに届くこと
11. **ホストとのBluetooth接続**
    - USBを外し、BLEのみでホストへ入力できること
12. **バッテリー駆動**
    - (手順3完了後)バッテリーを接続し、スライドスイッチONでUSBなしに動作すること。スイッチOFFで確実に停止すること
13. **充電確認**
    - バッテリー接続状態でUSB-Cを挿し、充電されること(電圧上昇または充電表示で確認)
14. **スリープ時消費電力**
    - アイドル→スリープ遷移後の消費電流を測定し、記録する(目標値は未設定。実測値を基準化する)
15. **ケース干渉確認**
    - ケース(または外形モック)と、USB-C・リセット・スライドスイッチ・nice!view・バッテリーの干渉がないこと

## 記録

- 各手順の結果(OK / NG / 条件付きOK)と気づきを [revisions/rev-a.md](revisions/rev-a.md) に記録する。
- NG項目はRev.Bの修正候補としてADR化を検討する。
- 左右両方について実施する(リバーシブルPCBの場合も両面それぞれ確認)。
