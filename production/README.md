# production/

発注に使用した**製造データの凍結スナップショット**をリビジョン別に置くディレクトリ。**まだ製造データは存在しない**(発注可能な状態ではない)。

## 構成(予定)

```
production/
└── rev-a/
    ├── gerbers/     # Gerber・ドリル
    ├── bom/         # BOM
    ├── placement/   # 座標データ(CPL)
    └── README.md    # 発注日・発注先・仕様・元コミットの記録
```

## ルール

- ここへ置けるのは、`docs/verification-checklist.md` の製造前チェックリストを完了したデータのみ。
- 置いたデータは**凍結**し、以後編集しない。修正は次リビジョン(`rev-b/` 等)として作成する。
- 製造用の生成物をこのディレクトリ以外に置かない(AGENTS.md参照)。
